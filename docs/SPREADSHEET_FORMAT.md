# Googleスプレッドシート ＆ Googleドライブ 連携フォーマット設計書（全媒体・列完全統一版）

**「X（旧Twitter）のシート」と「それ以外の媒体（掲示板・好き嫌い.com・5ch等）のシート」で、A列からAC列までの全29列の列位置・意味を100%完全に統一**しています。
また、これまで1セルに混在していた「発信者名・住所・電話番号/メールアドレス」も **M列（発信者名）・N列（発信者住所）・O列（連絡先：電話・メール）** に分離・統一したため、どの媒体でも同じ列番号でプログラム参照・集計・コピペ結合が可能です。
