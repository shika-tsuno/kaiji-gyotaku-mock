# Googleスプレッドシート ＆ Googleドライブ 連携フォーマット設計書（全6シート・発信者情報構造化・弁護士マスタ連動版）

1. **X（旧Twitter）と掲示板（5ch・好き嫌い.com等）でA列〜AJ列（全36列）の列位置を100%完全に統一**。
2. **発信者情報の構造化 ＆ 手動書き換えの手間ゼロ化（M〜S列）**:
   - 情報処理（名寄せ・内容証明作成・検索）しやすいよう **`M: 発信者氏名` / `N: フリガナ` / `O: 郵便番号` / `P: 発信者住所` / `Q: 電話番号（キャリア）` / `R: メールアドレス`** に分割。
   - **手動書き換えが面倒にならない工夫**:
     - **`S: 【自動結合】発信者情報まとめ`** 列に `=TEXTJOIN(...)` 数式をセットしているため、個別列を直せばまとめ表示も自動更新されます。
     - 逆に、従来の弁護士スプシのように **S列へ1セルまとめテキスト（住所・氏名・電話・メアドの塊）をコピペすると、GASの `onEdit` 自動トリガー（およびWebスプシの自動パーサー）が郵便番号・住所・氏名・フリガナ・電話・メールを自動判別してM〜R列へ一発で振り分け**ます！
3. **担当弁護士情報のマスタ連動（U〜W列 ＋ シート4 `担当弁護士マスタ`）**:
   - **`担当弁護士マスタ`** シートに弁護士情報（氏名・法律事務所名・電話番号・メール・報酬率）を登録。
   - 投稿目録シートでは **`U: 担当弁護士`** に名前（初期値：`神田 敬一`）が入っているだけで、**`V: 法律事務所名`** と **`W: 弁護士連絡先`** が `VLOOKUP` 数式で自動反映されます。連絡先変更時もマスタを1箇所直すだけで全案件に一括反映されます。

### U〜W列（3列）：担当弁護士情報（`担当弁護士マスタ` から自動反映・手入力不要）
| 列 | 統一項目名 | 内容・数式・例 |
| :---: | :--- | :--- |

| **V** | **【自動】法律事務所名** | 数式：`=IFERROR(VLOOKUP(U4,'担当弁護士マスタ'!$A$2:$F$20,2,FALSE),"")` → `神田法律事務所` |
