# Googleスプレッドシート ＆ Googleドライブ 連携フォーマット設計書

弁護士が実際に運用しているスプレッドシート（①掲示板の投稿記事目録、②Xの投稿記事目録、③費用・着手金残高管理）の列構成・数式を**100%完全維持**した上で、アプリの「案件詳細」「ホーム（ボール・ひよこ階段・マイルストーン）」「分析（ふりかえり理由・再挑戦）」「タスク」「証拠魚拓・書類」から逆算した管理項目を統合した全5シート構成です。

---

## シート3：`費用・入金管理`（添付3枚目完全準拠 ＋ 自動計算数式）

> 1行目：ヘッダー行 / 2行目：F2セルに初期着手金総額（例：`¥1,980,000`） / 3行目〜30行目：入金明細 / 31行目：合計行

### A〜G列：弁護士標準フォーマット（必須・添付3枚目準拠）
| 列 | 項目名 | 数式・入力ルール | サンプル値（添付3枚目） |
|---|---|---|---|
| **A** | 入金日 | 振込確認日を入力 | `2025/12/05`, `2025/11/25`, `2026/02/27`, `2026/04/20` |
| **B** | 相手方 | 示談・回収相手の氏名 | `森由里`, `新沼志麻`, `西村有佳里`, `丸山正雄・有子`, `黒須李稲` |
| **C** | 入金額 | 回収した示談金・賠償金額（31行目は `=SUM(C3:C30)`） | `200,000`, `100,000`, `100,000`, `150,000`, `100,000`（計 `650,000`） |
| **D** | 内報酬（税込み55%） | 数式：`=IF(C3="",0,ROUND(C3*0.55,0))`（31行目は `=SUM(D3:D30)`） | `110,000`, `55,000`, `55,000`, `82,500`, `55,000`（計 `357,500`） |
| **E** | 内着手金 | 数式：`=IF(C3="",0,C3-D3)`（45%を着手金回収へ充当。31行目は `=SUM(E3:E30)`） | `90,000`, `45,000`, `45,000`, `67,500`, `45,000`（計 `292,500`） |
| **F** | 着手金残高 | F2セル：`¥1,980,000`（初期着手金総額）<br>F3以降：`=F2-E3`（残高を自動減算） | `¥1,980,000` → `¥1,890,000` → `¥1,845,000` → `¥1,800,000` → `¥1,732,500` → `¥1,687,500` |
| **G** | 備考 | 分割・合算示談等のメモ | `#04・#05合算示談` 等 |
